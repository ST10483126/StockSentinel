# StockSentinel — Retail Inventory & Expiry Tracker

A lightweight desktop application that helps small retail businesses
and tuckshops track stock batches and flag items approaching expiry,
reducing financial loss from unsold goods.

## Problem
Small retailers lose thousands of Rands when stock expires on shelves
because they can't afford expensive inventory software.

## Features (planned)
- Add, edit, and delete stock items
- Track batches, suppliers, and expiry dates
- Flag items expiring within 30 days
- Calculate potential financial loss
- Reports exportable to CSV

## Tech Stack
- C# / .NET (Windows Forms)
- SQL Server LocalDB (dev) → SQL Server Express (later) 
- Entity Framework Core
- xUnit + FluentAssertions for testing
